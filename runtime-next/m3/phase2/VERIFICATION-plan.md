Consult `rejected_unique_uncovered` for union-based accounting, and remeasure each proposed range against the exact archived manifests.

`../dv1_splice.py` requires aligned, unambiguous, non-overlapping placement in one chunk, non-straddling data fields, complete original relocation-site equality, in-image resolved targets, and exact reference bytes after relocation. Its EXT tier X only places a target when all of its own relocations resolve and its bytes verify independently. It is not enough to compare labels or compiled raw pointer addends alone. `DESIGN-phase1.md` describes distinct causes: synthetic class names/class-vs-struct RTTI, unresolved virtual/deleting destructor symbols or purecall, and base-method vs derived-override targets. Historical estimates are not proven disjoint.

`direct-v1/game_state.py` is a read-only process probe for the existing custom image's preserved `.data`-relative layout, not an RTTI ABI inspector or proof of native-link layout. The last verified harness checks real cell IDs before save, after cell change and after quickload, plus clean exit. It does not establish complete game-state correctness or class/vtable identity.
