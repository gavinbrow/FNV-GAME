# PSA destructor ownership: implicit versus explicit

The private 2909 explicit-destructor proposal is **not ready to compile or integrate**. An existing compiled explicit `TESModelPSA::~TESModelPSA()` in `phase2-bgsbodypart-psa-hierarchy-proposal/0620.mirror.obj` has a 28-byte section and a PSA vtable-write relocation before the base-destructor call. The implicit destructor in the compiled `phase2-bgsbodypart-psa-implicit-proposal/0620.mirror.obj` and the rebased native BGS candidate is 19 bytes and has only the TESModel destructor relocation. The latter matches the original 0x0051b950 body and its relocation, as checked by the independent BGS EH owner review. An explicit user-defined destructor also performs automatic base cleanup, so manually calling the base again is not a faithful fix.

Current unit 2909 has 45 mapped functions and five listed EH tails. Its only 0x0051b950 source view is `FUN_0051b950_shell::FUN_0051b950`, which manually invokes the TESModel destructor; neither its source nor its included `TESObjectTREE.h` mentions TESModelPSA. Thus there is no identified natural 2909 use that emits an implicit PSA destructor, and adding a dummy object or explicit emission stub would not be source evidence. The old shell symbol appears only in unit 2909's own mapped entry.

The rebased private unit 620 candidate instead contains an actual PSA member in BGSBodyPart and naturally emits a defined `??1TESModelPSA@@UAE@XZ` from its destruction. A bounded next hypothesis is to move the existing 0x0051b950 19-byte recipe ownership from unit 2909's surrogate method to that emitted unit 620 native method, preserving address, extent and all other ownership entries. This must account for the now-unmapped surrogate body and prove no overlap or duplicate splicing. The move is not yet staged or accepted.

Both source units use VC9 SP1 with `/MT /Od /Oy- /GS /EHsc /Gy`; unit 620 additionally uses `/GF`. Before any owner transfer, verify source/preprocessor closures, all 620/621/2909 mapped functions and EH/relocations, the natural PSA destructor and weak scalar/vector deleting wrappers, candidate literal-pool bindings, actual production COFF and unique linker placement. RTTI/vtable ABI and final runtime remain separate. The existing explicit 2909 experiment and prior compiled evidence are preserved unchanged.
