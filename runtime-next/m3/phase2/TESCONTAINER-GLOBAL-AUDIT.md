# TESContainer global source-view audit

The corrected lexical scan finds 25 syntactically global definitions, **including the installed canonical header**, plus eight namespaced definitions outside this audit. The previous saved scope registry preserved the category counts but undercounted some line numbers: its preprocessor masking could consume preceding newlines. This audit recalculates source lines with newline-preserving masking and records file hashes, declared method names and all recipe-function addresses reached by the supported quoted-include closure in `tescontainer_global_audit.json` (`tescontainer_global_audit.py` reproduces it). It does not evaluate conditional compilation, macro-generated includes or ODR/ABI equivalence. Unit sets are review scopes, not proof that every lexical include is active or that no macro include exists.

The canonical `include/TESContainer.h` declares a 12-byte, pack-4 class derived from `BaseFormComponent`, with an eight-byte `BSSimpleList<InventoryStackRecord*>` at +4 and virtual Init, Free, CopyFromBase and CompareWithBase. A same-size view is not automatically the same C++ class: pointee types, virtual slot declarations, method names and existing emitted symbols matter.
