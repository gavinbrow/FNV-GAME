# Lane two normal CRT contracts

The accepted lane-two evidence supports 16 positive named SP1/RTM models. A
normal functional provider would use fresh normal CRT code and state. Original
dependency addresses are retained as evidence, never copied or preserved by
aliasing old heap, locale, errno, stream or exception state. No runtime ABI or
provider adoption is approved here.

Only `0x00ecc071` / `code` is an unresolved name in the pinned actual V4
diagnostic cohort. Its proposed diagnostic binding is the canonical undefined
name from that exact group to native SP1 `__wcsicmp`. The normal public boundary
is `int __cdecl _wcsicmp(const wchar_t*, const wchar_t*)`, with 16-bit character
storage in this x86 CRT. The actual main field passes two pointer words and
tests a signed integer result. The recovered variadic declaration remains in
the record; the second string's extent, termination and lifetime remain a DATA
owner gate. The old locale-change, errno and invalid-parameter dependencies are
not independently identified by the instruction comparison.

The diagnostic scope is exactly main recipe0576, original root `0x0086a850`,
field +768, physical symbol1420. Source metadata names section199; the retained
projection names section2. The binding-row hash joins those representations;
neither section number is silently substituted for the other. A linker alias
is global to its canonical name, so every included use must appear in the
aggregate current-cohort census. The single current field does not constrain a
future larger component automatically.

The other 15 positive models remain future contracts and receive no diagnostic
alias from this lane. Their machine boundaries and material assumptions are:

| Native symbol | Normal boundary | Material ownership or caller gate |
|---|---|---|
| `_memset` | cdecl pointer/int/size_t → pointer | Writable extent; returned pointer versus recovered void declarations |
| `_strcpy_s`, `_strcat_s` | cdecl char*/size_t/const char* → errno_t | Capacity, termination, overlap and normal invalid-parameter/errno policy; recovered pointer/void returns |
| `_sprintf` | cdecl char*/format/... → int | Actual x86 variadic argument types, destination extent and formatting/locale/error policy |
| `_strstr` | cdecl two const char* → pointer | Terminated inputs, borrowed-result lifetime; recovered int aliases |
| `_strncmp` | cdecl two const char*/size_t → int | Readable bounded inputs, signed result and count range |
| `_memmove_s` | cdecl void*/size_t/const void*/size_t → errno_t | Extents and errno policy; conflicting pointer-return and argument-order declarations |
| `__access` | cdecl const char*/int → int | Path lifetime, valid access-mode value and normal filesystem/errno policy |
| `_strtok_s` | cdecl char*/delimiters/char** → char* | Mutable buffer, persistent caller-owned context and borrowed token lifetime |
| `_isalnum` | cdecl int → int | Valid unsigned-character/EOF domain, classification locale and nonzero truth semantics |
| `__strlwr_s` | cdecl char*/size_t → errno_t | Mutable terminated buffer, locale and invalid-parameter/errno policy; recovered pointer return |
| `_fwrite` | cdecl buffer/size_t/size_t/FILE* → size_t | Unified fresh CRT FILE, descriptor, buffer, lock/error and open/use/close lifecycle |
| `__msize` | cdecl void* → size_t | Live allocation from the same normal CRT heap; recovered source prototype absent |
| `__allmul` | native compiler helper | No manufactured public C prototype; actual generated 64-bit operand/result/cleanup contract remains open |
| `__CxxThrowException@8` | observed two-word stdcall caller boundary | Actual exception and throw-info types, rethrow semantics, destructors and compatible EH family remain open |

These are proposed normal function contracts, not proof that every recovered
declaration conforms. Native compiler-helper spellings are exact inspected
exports; public typed helper prototypes are deliberately unresolved where the
saved header/source evidence does not establish them.

The rejected direct `_atol` and `__stricmp` models remain excluded. The five
shared/interior section models and 25 targets without a named model also remain
excluded. Full nonrelocation agreement does not justify adding these other
targets to a diagnostic map.

The private contract artifact preserves all 529 physical fields of the positive
models, each exact native archive/member identity, every observed relocation
obligation, source/header declarations, and current actual-group scope. It emits
no object or alias. A separate reviewed diagnostic projection may use the one
eligible binding; it must preserve the remaining unresolved CRT/IAT groups,
normal library ownership, real linker diagnostics and all runtime gates.
