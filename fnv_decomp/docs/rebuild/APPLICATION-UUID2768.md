# UUID2768 application consumer

`application_uuid2768.py` is a pure derived-artifact adapter for a future combined cohort. It does not link, read the SDK, select a provider, adopt a manifest, run the game, or change the original negative certificate. Source and dependency imports require independent pin review by the calling integration before use.

`consume(evidence)` accepts exactly the named byte strings in `PINS`. It checks all raw SHA-256 identities before parsing, joins the accepted producer and handoff reviews with the separate native receipt/review and dependency declaration/audit, checks the saved before/after 58-byte comparisons, preserves all nine original and normalized field proofs, verifies the two original UUID directive occurrences and full 93-byte payload, and strictly parses the derived one-member archive and object. Only after those typed checks does it call `application_link_frontier.ordinary_member` as a physical field mapper. The result contains one candidate provider and nine mapped fields; its false `base_closure_observed`, provider, ABI, and runtime fields remain authoritative. It does not turn the original negative into an ordinary positive.

`guard_response(tokens, fresh_identity, qualified)` takes already-parsed response tokens and a caller-supplied physical identity with exactly `path`, `sha256`, `device`, `inode`, and `size`. It requires the exact reviewed full normal UUID library path once, rejects alternate or unqualified UUID requests, and compares all five identity values with the accepted declaration. It performs no I/O and cannot establish that the caller's identity is fresh. The integration owner must independently observe that physical identity immediately before use, enforce the same response guard and no shadowing, and retain the independent review and applicable source, input, native, oracle and cohort gates. Passing the guard does not prove library selection, loading, duplicate no-op semantics, ABI, or runtime readiness.

The separately accepted native review is structural evidence for the exact derived archive; the historical producer and typed handoff retain their original `native_archive_conformance_verified: false` values. No singleton LINK or new exclusion epoch follows from this adapter.
