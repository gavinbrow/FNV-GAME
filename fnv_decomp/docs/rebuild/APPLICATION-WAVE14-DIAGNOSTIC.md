CODE21 cohort, and qualified UUID2768 component. It does not invoke a linker,
execute the game, adopt a provider, or establish ABI or runtime eligibility.
The saved UUID negative certificate and the qualified composition remain distinct.

Actual operation requires a fresh independently reviewed source/input/watchdog
packet, a unique coordinator lease, the preparer-specific durable child record
and nonce, and the fixed interpreter. Startup owns the launcher. No operation is
authorized merely by the existence of this source or its input manifest.

The loader authenticates the complete 69-module source snapshot before project
imports and lazily executes only modules required by the reviewed computation.

search-path reinsertion, and rejects unreviewed external dependencies. The Python
standard library, the entire psutil package including bytecode, and the operating
system are explicitly trusted runtime components. Three psutil file hashes are
installation indicators; they are not a proof of all executed package bytes.

ordered old field records and unknown values, verifies the typed UUID consumer,
replays the existing IAT census and validates the CRT contract against its entire
saved peer validation, then applies the fixed V13 combined response transform.

all inherited physical-binding records and the six prior quarantines.

Each stability phase uses the reviewed exact-record selection utility and the
unchanged diagnostic stability delegate. Equal complete identities are checked
once within each phase; aliases remain distinct, the original full ledger remains
intact, and each subsequent phase selects and checks afresh. Fewer observations
within a phase are disclosed and do not imply unconditional equivalence under
arbitrary concurrent file changes. Publication uses exclusive file creation and
rechecks the lease and stability through each stage; partial failures are retained.
