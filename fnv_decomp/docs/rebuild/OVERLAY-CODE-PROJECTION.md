# Separate overlay CODE projection with existing caller names

`overlay_code_projection.py` is a new source-only collector/projector for the
accepted alternate-object registry. It does not modify the original 12,946-root
archive, original provider selection, entry object or frozen ordinary observer.
The input universe is exactly the registry's nine objects, thirteen requested
alternate roots, 931 complete function rows and 22 repaired fields. The 918
unselected same-TU definitions do not become exports.

The fixed policy is `runtime/code-pools/overlay-repaired-code-v1.json`, SHA-256
`ba5c84ef938baa12c05dc27a17b880f73592118e3869526d43f8fc7266050b79`.
Independent source/test review passed before the bounded operations recorded
below. Observation and private projection are explicit separate CLI modes;
projection additionally requires `--authorize-private-emission` and the owned
reference for unchanged plain comparison.

## Logical identity stays compatible

An alternate export keeps the original selected provider's existing logical
name: `runtime_code_pool.canonical({recipe_id, object_sha256, symbol_index})`,
using the **baseline** selected recipe/object/primary index. The actual overlay
object, generated source, new primary/section/value and overlay registry identity
remain distinct provenance. The exporter never hashes a new object/index into a
new caller-visible name and never chooses a provider by equal bytes or spelling.

The complete pinned 68,657-owner inventory supplies the original logical map.
Every row joins its exact original selection and original manifest object and
native span. For each requested root, the registry's original ancestry and
old primary index must equal that same baseline identity. Both complete baseline
coverage and all member export names are checked: an `EMITTED` baseline physical
provider or any existing matching logical export blocks the alternate. The
original archive itself is hash-pinned before and after. A later package
assembler must preserve this replacement exclusion contract; this tool does not
override an existing strong definition or alter the old archive.

Referenced unretained same-TU CODE definitions become undefined references to
the exact old global selected provider, with unchanged field bytes/addends and
physical-index provenance. They are not retained or exported merely because
they share the source object. A CODE target without an exact, unique selected
entry remains blocked. A retained local offset stays local, without creating a
new callable interior provider.

Exact unowned DATA, IAT-cell and CRT demands retain the established unresolved
domain names and original base/target/addend metadata. Those obligations are
unfulfilled link/storage/ABI contracts, not materialized data or adopted runtime
providers. Unknown roles, ambiguous CODE identities, source placeholders,
unproved conversions and unsupported non-CODE alias groups remain blockers.

## Fresh native closure, not relabeled v3 proof

The pure core reuses `root_code_closure.assess_object` at exact SHA-256
`4bfdb5001380a3d7e5db7517033285d49ab211be68e2fcba15964f0ad5b03c53`
and parser `coff_code_archive.parse` at
`76244d2d4dca4c1f8aa72224be1ef5c92f68976b5cda7d31b5cfe23d3cc29e64`.
The ordinary collector and its completed leaf work remain untouched. Its
original-only request validator is not bypassed or fed a changed object hash;
the overlay lane has its own explicit contract builder and provenance schema.

Before closure, the driver verifies every complete saved ordinary comparison
row, fresh function placement, full section/primary/auxiliary inventory and all
15,273 physical fields against the actual accepted objects. Every fresh source
binding joins its new object/source/unit identity, exact field/target record,
operand, overlap count and native parent span. Each whole root's ordinal/hash
list must match the accepted root-context stream. Original source/object/recipe
ancestry stays separate from the current object and generated source hashes.

The observer's complete-function proof flags mean the fresh registry function
rows, placements and fields are complete. They are not a new v3 receipt or a new
EH byte proof. Parent-frame obligations are observed from current native anchor
references and associations. Exact original parent EH lineage remains an
explicit unclosed obligation. The frozen observer also rechecks all hidden
indices, children, weak/common records, directives, omitted definitions,
SafeSEH, names and physical uses under the exact retained root set. No original
EH absence list is silently reused as a fresh empty list.

The three partially repaired requested owners retain their missing-field
blockers. For each recipe, the implementation considers only fully repaired
requested roots and tests finite subsets largest-first, with lexical tie
breaking. At most three such roots occur in one recipe. Every subset gets a
new complete observer contract and fresh whole-set closure; one-root drop lists
are never unioned. Only a subset with both closure and namespace proof can be
a serialization candidate. No actual eligible subset count is asserted before
observation, and the theoretical maximum ten roots is not a target to force.

The separate local `$finished$...` bookkeeping witness does not approve its
omission. The unchanged observer understands a narrower omitted `$LN...` form;
an unsupported local label can therefore block a whole source object. This
producer does not waive that blocker, rewrite its name, or invent an EH policy.
All seven remaining missing fields in the registry's nine TUs stay in every
result, including the unrequested field outside the entry-reachable subset.
The original entry/global 47/88 censuses remain unchanged.

## Namespace, conversion and pure projection

The namespace plan retains separate physical records. Compatible duplicate CODE
names require one exact original logical provider, at most one retained strong
definition, ordinary function records and complete exact zero-addend selected
entry field proofs. Defined members outside the retained set must have explicit
observer conversion dispositions. A group cannot merge records or redirect a
relocation. Different bases, mixed roles/types, hidden uses or non-CODE duplicate
groups block it.

Projection first applies the unchanged strict serializer's exact section,
primary and auxiliary bijections and explicit undefined conversions. A guarded
name-only pass then applies the certified logical names while preserving all
section payloads and relocation targets. The output must export exactly the
chosen old logical root names, with no additional same-TU definitions. It is
reparsed and compared to the original reference through the unchanged comparator
and a complete selected-root resolver assembled from the field proofs. Raw
operands and section bytes are not patched.

If any candidates are emitted, a separate private `overlay-code.lib` contains
only those new objects and is recovered with the existing archive reader. The
original CODE archive is never appended to or replaced. Every emitted object,
plan, comparison, namespace/omission receipt and archive is hash-recorded and
rechecked. Failures preserve their exact outputs and journal; no automatic retry
or native tool exists. Checkpoints bound the operation to ten minutes, one GiB
observer memory and 100 MiB private output. Hashes and optional-index absence
are checked before/after, including at a failed terminal boundary.
