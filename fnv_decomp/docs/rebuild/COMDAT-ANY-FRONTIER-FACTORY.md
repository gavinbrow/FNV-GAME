# COMDAT ANY frontier projection factory

`comdat_any_frontier_factory.py` is a new versioned operational adapter over the
accepted COMDAT witness, composer, and pure consumer. All previous producers,
serializers, observer, and selectors remain frozen. Development and initial
review use authored fixtures only. Actual projection requires its own exact
source/input review and delegated bounded operation; synthetic passes do not
authorize an actual run.

The CLI accepts `--operation`, `--operation-sha256`, `--review`,
`--review-sha256`, `--provider-map`, `--reference`, and `--out`. The operation is
exactly:

```
schema_version: 1
kind: finite-comdat-any-frontier-projection-operation
epoch: explicit ASCII label
roots: the entire sorted composed-complete observer subset
output_relative: new private build/rebuild directory
resource_limits: {seconds: 900, peak_memory_bytes: 1073741824,
                  output_bytes: 134217728}
artifacts: the exact ARTIFACTS map in the source
acceptances: the exact ACCEPTANCES map in the source
source_contexts: exact prior observer authority descriptors, filtered only
                 to the entire eligible subset and its required lanes
provider_map_sha256: accepted complete planned-map hash
reference_sha256: unchanged owned-reference hash
```

Every artifact/acceptance reference is `{path, sha256}`. Metadata and original
context references resolve under private `build/rebuild`; the immutable recipe
and image-check metadata may resolve elsewhere inside the project. Source
descriptors retain the observer's exact `{kind, receipt, request, details}`
schema. Both independent actual observer outcome reviews, its original request,
context and input review, and the fixed source acceptances are bound. The
operation includes the accepted CODE68 producer/member/handoff/outcome review
artifacts and the separately saved latest exclusion epoch. No circular latest
epoch outcome review is needed: the actual input phase reconstructs its bytes.

`select_eligible(receipt, rows, request)` accounts for every observer record and
all requested roots, preserves every blocked occurrence and ordinal, and selects
all complete compositions. Native qualification alone, partial witnesses, or a
restamped composition flag cannot substitute for completeness. Base, contract,
source, wrapper, census, root, original certificate, discharge occurrence, and
false approval flags are joined. An empty eligible set cannot create a fake
projection. There is no hardcoded one-root eligibility rule or size sampling.

`rebuild_latest_exclusions(parent, code68_members, providers_expanded, units,
source_member_sha)` is a thin pure metadata constructor. It preserves every
14,409-record upstream V8 entry verbatim, checks the original physical root,
source, planned identity, canonical export, comparison receipts, and numeric
serialized maps for every one of the 68 accepted members, then appends only that
cohort. Original symbol indices such as 31 remain original namespace identities
even when their serialized output index is zero. The resulting ordinary and
collision counts are 14,471 and 14,477. Those counts confer no provider or
application adoption. The unrelated synthetic cohort-preparation prototype is
not a dependency or admission authority.
