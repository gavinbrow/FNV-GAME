# Combined V13 response transform

`application_combined_response.transform` is a pure source-only token transformation. Its public entry point accepts the raw V13 response bytes only when their SHA-256 is `d90fe3f379b130927fc5fe98821919f7016e69d657cc2023072556ef3d60d389`. There is no public alternate-baseline argument. Its private `_transform` exists solely to exercise authored fixtures and must never be called by an operational integration.

The caller supplies canonical absolute Windows paths for the exact predecessor and successor output directories and two distinct future batch and UUID archive paths, the exact 34 inherited IAT and four inherited CRT aliases, independently reviewed current subsets, the qualified `application_uuid2768.consume` result, and a caller-observed UUID SDK identity. The helper checks one fully quoted token per line; rejects duplicate tokens, unexpected alias or output switches, existing new archives, noncanonical paths and unreviewed alias additions; replaces exactly one `/OUT` and `/MAP`; removes all 38 inherited aliases; then appends both archives, the exact declared full UUID path once and the reviewed subsets. It calls the unchanged UUID response guard and the unchanged diagnostic renderer, then independently reparses its own output and checks token identity. The unchanged guard rejects an output directory containing a standalone `uuid` path segment; a destination such as `application-link-diagnostic-v14-combined` avoids that conflict.

The calling integration must authenticate the V13 baseline's independent authority, all path and alias inputs, the complete whole-cohort IAT/CRT proofs, and the accepted producer handoffs. It must establish and recheck UUID SDK physical identity and search-path shadowing by separately authorized I/O; the response helper performs none. The caller must also require a nonempty independently accepted batch, preserve every quarantined root and all old field records, and bind any accepted archive's exact bytes and native/MATCH evidence. These obligations are not inferred from a path or token.

A successful result is a response plan only. It does not publish a file, select a provider or library, establish library loading or ABI/runtime readiness, or run LINK. No UUID singleton link or operation is authorized by this helper.
