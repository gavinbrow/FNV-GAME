# Typed singleton COMDAT integration

`application_typed_comdat.consume` authenticates the complete saved finite observer
set through the accepted factory's `select_eligible` function. It joins the one
selected row to its typed handoff and serialized member. Observer stream ordinal
and earlier source-authority ordinal are separate identifiers.

The consumer parses only the derived archive. It checks the exact canonical
export, original root identity, section/primary/auxiliary maps, unchanged Selection2
record and checksum, CODE payload hash, zero relocations and undefined symbols,
and the exact retained 47-byte LIBCMT/OLDNAMES directive payload. It consumes no
new directive normalization or provider-selection policy.

This authenticates saved negative/composed/census evidence. It does not replay
original-object ownership policy or change the original negative certificate.
The caller must first bind the factory and transitive source hashes, accepted
producer/physical/native reviews and exact archive identity. Fresh collision,
field-preservation, CRT/IAT census, prepared response and native-driver reviews
remain required before a separately leased diagnostic LINK. No execution or
runtime compatibility follows from this consumer.

Tests use authored COFF only and cover stale payloads, altered Selection2 or
checksum, hidden directives, owner-map changes and attempted approval promotion.
