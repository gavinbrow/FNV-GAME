# COMDAT ANY CODE candidate policy

`comdat_any_code_omission.py` is a new pure, opt-in metadata witness for one
original selected CODE root with COMDAT auxiliary Selection 2 (`ANY`). Its
initial scope is source and authored synthetic tests. It does not read original
game artifacts, write objects, rename symbols, change a selection value or
integrate into a composer or writer.

The frozen ordinary observer reports `UNSUPPORTED_OR_PARTIAL_ROOT_SECTION`
when any root extent, name, flag or auxiliary-selection conjunct fails. The
legacy global writer separately reports `UNSUPPORTED_ROOT_COMDAT`. This
candidate policy binds the exact original ordinary blocker ID and full native
root evidence. It proves every other conjunct already holds: one owned
storage-2 function definition, value zero, complete checked section extent,
`.text` with exact flags, and one known section-definition auxiliary with
Selection 2. Partial sections, flags, aliases and hidden auxiliary indices
cannot borrow that same blocker spelling to obtain a discharge.

The API requires the original bytes, full contract, unchanged negative ordinary
certificate, exact ten-field root and declared planned-definition census. The
`policy_id` keyword has no default. The original observer is freshly replayed;
source, object, recipe and checked native identity are bound before evaluating
the candidate. Invalid opt-in, schemas, identities or incomplete census raise
an error. Unsupported native forms or missing, multiple or stale declared
definitions return a blocked witness with no discharge.

The census has this exact form:

```json
{"schema_version":1,"kind":"planned-code-definition-census","complete":true,
 "entries":[{"root":{},"planned_canonical_name":"..."}]}
```

Each `root` is the complete ten-field physical identity; each planned name must
derive from its original recipe, original object hash and original numeric
symbol index. Exactly one relevant entry must equal the requested root. This
is a declared synthetic evidence condition. Census authentication, actual
prepared-export exclusion, future namespace adoption and global linker
uniqueness remain unproved. No current prepared manifest is read or adopted.

The initial profile rejects DATA sections and retained DATA/IAT references,
weak/common lookup, aliases, multiple root definitions, class 6 labels, unknown
associations and selections, hidden indices, and EH, TLS, CRT, SafeSEH or other
special contexts. Only the frozen observer's exact proved debug-only omission
form is recognized. Independent blockers and their occurrence multiplicity
remain untouched. The witness cannot waive field semantics or another typed
policy; separate evidence and a separately reviewed consumer would be needed.

The witness records exact flags, decoded auxiliary, original primary indices,
physical-slot scope, payload and relocation hashes, and relocation addend bits.
Selection stays 2 and no byte is changed. Only a complete candidate can propose
the one exact root-conjunct ID for discharge. The negative certificate is never
rewritten or replaced with a positive certificate. All emission, serializer,
namespace, provider, runtime and global-link approval flags remain false.

retroactively promote cached observations or authorize original-artifact reads,
object production, a service change, linking or execution. The original frozen
observer, parser, serializers, composer and global writer remain unchanged.
